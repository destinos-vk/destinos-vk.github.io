CIRA · AD-02 · iPhone Replay QA

Точная проверка способа повторного запуска. Во всех режимах один и тот же MP3 из TTS Gateway, без тишины, без WAV и без новой генерации при повторных нажатиях.

После загрузки проверь сначала L (старый механизм). Между запусками жди завершения звука.

L — Старый AD-02

Один аудиоэлемент, 180 мс беззвучного воспроизведения, перемотка в 0, задержка 45 мс, повторный play(). Аналогично опубликованной главе 4. 0 запусков · 0 обрезаний

R — Повторное использование без прогрева

Один аудиоэлемент, без беззвучного запуска. Есть сброс времени и повторное назначение MP3. 0 запусков · 0 обрезаний

N — Новый аудиоэлемент

Каждое нажатие создаёт новый элемент, запускает тот же MP3 сразу, без перемотки или прогрева. Аналогично независимому успешному тесту. 0 запусков · 0 обрезаний

Результат

Начни с L, прослушай его 10 раз, затем R и N. Нажимай «Начало обрезало», только когда дефект услышан.

Готов к загрузке.

Тест не изменяет Ghost, Cloudflare Pages или R2. Он использует существующий аудиокеш Gateway. Если L обрезает, а R и N нет — проблема в беззвучном прогреве и перемотке, а не в MP3.
